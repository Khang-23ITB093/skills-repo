# Multi-Model Escalation Rule

**Always-On Directive for All Projects:**

When working on ANY project, if you encounter a complex problem, recurring bug, or a task that requires deep architectural reasoning (such as race conditions, complex networking, or core system design), you must automatically act as a **Model Orchestrator**. 

Do not struggle repeatedly with the same issue or generate multiple failed attempts using a Workhorse model. Instead:
1. Stop and evaluate the difficulty of the issue.
2. Refer to the `multi-model-orchestration` skill to select an appropriate model.
3. Proactively advise the user to escalate the task to a more capable reasoning model (such as **Claude Sonnet 4.6**, **Claude Opus 4.6**, or **GPT-OSS 120B**).
